Фронтенд‑приложение для сервиса психологической помощи, написанное на React + TypeScript и собраное с помощью Vite.

## Архитектура проекта

Проект организован по подходу Feature‑Sliced Design (FSD) с разделением на слои `app`, `pages`, `widgets`, `features`, `entities`, `shared`.[2][4][1]

- `src/app` — инициализация приложения: корневой компонент `App.tsx`, маршрутизация, провайдеры (например, React Router, QueryClient, тема), глобальные стили `App.module.scss`.[5][1]
- `src/pages` — страницы приложения ; каждая страница собирает виджеты и фичи и отвечает за конкретный URL‑маршрут.
- `src/widgets` — крупные самостоятельные блоки интерфейса, которые могут переиспользоваться на разных страницах (например, общий layout, блок навигации, панель фильтров).
- `src/features` — функциональность с бизнес‑ценностью и пользовательскими сценариями (формы, фильтры, модальные окна, операции подтверждения/отмены, авторизация и т.п.).
- `src/entities` — бизнес‑сущности домена (пользователь, консультация, и т.п.): типы, запросы к API, хранилище состояния и базовая логика работы с ними.
- `src/shared` — переиспользуемые, не завязанные на конкретную бизнес‑область модули: UI‑кит, утилиты, хелперы, константы, общие стили, базовая работа с HTTP и т.п.
- `src/tests` — конфигурация и вспомогательные утилиты для unit‑ и component‑тестов (например, `setup.ts`).  
 

Такая иерархия упрощает переиспользование сущностей и фич, а также ограничивает зависимость верхних слоев от нижних, что является ключевым принципом FSD.

## Быстрый старт
1. Установите зависимости:

   ```bash
   npm i
   ```

2. Запустите дев‑сервер:

   ```bash
   npm run dev
   ```

3. Откройте в браузере:

   ```text
   http://localhost:3000
   ```

Vite поднимает локальный dev‑сервер с горячей перезагрузкой для быстрого развития.

## Скрипты

В проекте используются следующие npm‑скрипты:

```bash
npm run dev      # запуск Vite dev-сервера
npm run build    # типизация (tsc -b) и production-сборка в папку build
npm run preview  # локальный предпросмотр production-сборки
npm run lint     # проверка кода ESLint
npm run test     # unit- и component-тесты
npm run start    # запуск мокового backend-сервера
npm run server   # запуск production-сервера backend-а
```

Vite по умолчанию предоставляет скрипты `dev`, `build` и `preview`, которые здесь дополнены типизацией и линтингом.

## Линтинг и стиль

- Линтинг кода:

  ```bash
  npm run lint
  ```

- В проекте используется единый стиль форматирования кода; для автоматического форматирования рекомендуется Prettier (подключён в `devDependencies`). Интеграция ESLint + Prettier — стандартный подход для проектов на Vite и React.[3][10]

## Сборка и предпросмотр

Сборка проекта:

```bash
npm run build
```

Предпросмотр production‑сборки:

```bash
npm run preview
```

Сборка попадает в папку `build`, а `preview` поднимает локальный статический сервер для проверки продакшн‑версии приложения.
